# MONO — личные финансы (приложение для iPhone)

Это нативное iOS-приложение на Swift. У него своя иконка на экране «Домой» и запуск на весь экран без Safari, всё работает без интернета. Данные хранятся только на телефоне. Импорт выписок Kaspi (PDF) тоже работает офлайн, потому что модуль чтения PDF лежит внутри приложения.

Собрать iPhone-приложение можно только на Mac. Поэтому сборку делает бесплатный Mac-сервер GitHub, а вы ставите готовый файл `MONO.ipa` с компьютера на Windows.

---

## Шаг 1. Собрать MONO.ipa на GitHub (один раз, ~10 минут)

1. Зарегистрируйтесь или войдите на https://github.com.
2. Нажмите **New repository**. Название, например, `mono-ios`, тип **Public** (для публичных репозиториев сборки бесплатны без ограничений). Нажмите **Create repository**.
3. На странице репозитория нажмите **uploading an existing file**.
4. Распакуйте этот архив и перетащите в окно браузера **всё содержимое** папки `MONO-iOS` (папки `MONO`, `Web`, `.github` и файлы `project.yml`, `README.md`). Нажмите **Commit changes**.
   - Проверьте, что в репозитории есть папка `.github`. Если её нет, выберите **Add file → Create new file**, в имени файла напишите `.github/workflows/build-ipa.yml`, вставьте содержимое этого файла из архива и сохраните.
5. Откройте вкладку **Actions**. Сборка «Сборка приложения для iPhone» запустится сама. Если не запустилась, нажмите на неё и затем **Run workflow**.
6. Когда появится зелёная галочка (через 5–10 минут), откройте сборку. Внизу в разделе **Artifacts** скачайте **MONO-ipa** и распакуйте его. Внутри будет `MONO.ipa`.

## Шаг 2. Установить на iPhone с Windows через Sideloadly

1. Установите **iTunes** с сайта Apple (версия для Windows с apple.com, **не** из Microsoft Store) и **Sideloadly** с https://sideloadly.io.
2. Подключите iPhone кабелем, разблокируйте его и нажмите «Доверять этому компьютеру».
3. В Sideloadly перетащите `MONO.ipa`, введите свой Apple ID и нажмите **Start**. Sideloadly подпишет приложение вашим Apple ID и установит его.
4. На iPhone:
   - **Настройки → Основные → VPN и управление устройством**: выберите свой Apple ID и нажмите «Доверять».
   - На iOS 16 и новее: **Настройки → Конфиденциальность и безопасность → Режим разработчика** — включите и перезагрузите телефон.
5. Откройте MONO с экрана «Домой».

### Важно про бесплатный Apple ID
- Приложение, подписанное бесплатным Apple ID, работает **7 дней**. Потом подключите телефон и снова нажмите Start в Sideloadly. **Данные при этом сохраняются**, если не удалять приложение.
- Чтобы не переподписывать каждую неделю, нужен платный Apple Developer ($99 в год). Тогда подпись действует год, и можно раздавать приложение через TestFlight.

### Про данные
Операции хранятся внутри приложения, отдельно от сайта в Safari. Чтобы перенести данные из веб-версии: в веб-версии откройте **Резервная копия → Скопировать**, затем в приложении откройте **Резервная копия**, вставьте текст и нажмите **Восстановить**. Так же стоит делать копию перед переустановкой приложения.

## Для разработчика

| Путь | Что это |
|---|---|
| `Web/index.html` | Интерфейс MONO (тот же, что и веб-версия, PDF.js грузится из `Web/pdfjs/`) |
| `MONO/WebViewController.swift` | Экран приложения (WKWebView): ссылки, alert/confirm |
| `MONO/LocalFileSchemeHandler.swift` | Отдаёт файлы из `Web/` по адресу `mono://app/…` (стабильный адрес, чтобы localStorage не терялся) |
| `MONO/Assets.xcassets` | Иконка 1024×1024 и цвет экрана запуска |
| `project.yml` | Описание проекта для XcodeGen |
| `.github/workflows/build-ipa.yml` | Сборка неподписанного `MONO.ipa` на GitHub |

Сборка на Mac: `brew install xcodegen && xcodegen generate && open MONO.xcodeproj`, затем в Xcode выберите свою команду в Signing и нажмите Run.
